# Process and Workflow

This directory contains rules and guidelines for project management and workflow processes.

## Rules

### PRD Creation (`create-prd.mdc`)
- Product requirements documentation
- Feature specification
- User story mapping
- Requirements gathering

### Task Management
- Task Generation (`generate-tasks.mdc`)
  - Task creation guidelines
  - Task prioritization
  - Resource allocation
  - Timeline planning

- Task Processing (`process-task-list.mdc`)
  - Task execution workflow
  - Progress tracking
  - Quality assurance
  - Completion criteria

## How to Use

### Quick Start Guide

1. **PRD Creation Process**
   ```bash
   # 1. Initial Setup
   - Create PRD template
   - Set up project repository
   - Configure documentation tools

   # 2. Requirements Gathering
   - Collect stakeholder inputs
   - Document user stories
   - Define acceptance criteria

   # 3. Documentation
   - Write feature specifications
   - Create user flow diagrams
   - Document technical requirements
   ```

2. **Task Management Workflow**
   ```bash
   # 1. Task Generation
   - Break down features into tasks
   - Assign priorities
   - Set deadlines
   - Allocate resources

   # 2. Task Processing
   - Track progress
   - Update status
   - Conduct reviews
   - Document completion
   ```

### Practical Examples

1. **PRD Template**
   ```markdown
   # Feature: User Authentication
   
   ## Overview
   Implement secure user authentication system
   
   ## User Stories
   - As a user, I want to log in securely
   - As a user, I want to reset my password
   
   ## Acceptance Criteria
   - [ ] Login form validation
   - [ ] Password reset flow
   - [ ] Security measures
   
   ## Technical Requirements
   - OAuth 2.0 implementation
   - JWT token handling
   - Password hashing
   ```

2. **Task Generation**
   ```markdown
   ## Task: Implement Login Form
   
   ### Subtasks
   1. Create login form UI
   2. Implement form validation
   3. Add API integration
   4. Write unit tests
   
   ### Dependencies
   - Backend API ready
   - Design assets available
   
   ### Timeline
   - Start: 2024-03-20
   - End: 2024-03-25
   ```

3. **Task Processing**
   ```markdown
   ## Progress Tracking
   
   ### Daily Updates
   - Morning: Review tasks
   - Afternoon: Update progress
   - Evening: Plan next day
   
   ### Status Updates
   - In Progress: UI implementation
   - Completed: Form validation
   - Blocked: API integration
   ```

## Best Practices

1. **PRD Creation**
   - Keep requirements clear
   - Include all stakeholders
   - Document assumptions
   - Define success criteria

2. **Task Management**
   - Break down large tasks
   - Set realistic deadlines
   - Track dependencies
   - Regular updates

3. **Workflow**
   - Follow defined process
   - Regular communication
   - Document decisions
   - Review progress

## Common Pitfalls

1. **PRD Issues**
   - Unclear requirements
   - Missing stakeholders
   - Incomplete documentation
   - Unrealistic timelines

2. **Task Management**
   - Overly large tasks
   - Unclear priorities
   - Missing dependencies
   - Poor tracking

3. **Workflow**
   - Process deviations
   - Poor communication
   - Missing updates
   - Incomplete documentation
